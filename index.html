Learn to build, run and defend IT infrastructure.

The PG Diploma in IT Infrastructure, Systems and Security (PG-DITISS) from C-DAC trains you in servers, networks, cloud and cyber security, with hands-on lab work throughout.

What you will study

The syllabus is updated by C-DAC from time to time. These are the main areas covered.

IT Infrastructure fundamentals

Computer architecture, data centre basics and how enterprise IT is put together.

Linux administration

Users, permissions, services, package management, shell scripting and automation.

Windows server and directory

Installing and managing Windows Server, Active Directory, DNS, DHCP and group policy.

Networking

TCP/IP, routing, switching, VLANs, firewalls and network troubleshooting.

Virtualization and cloud

Hypervisors, virtual machines, containers and cloud deployment concepts.

Information and cyber security

Threats, hardening, vulnerability assessment, logging, SIEM and incident handling.

Scripting and automation

Python and shell scripts to automate routine administration tasks.

Capstone project

Design, deploy and secure a small infrastructure end to end.

Who can join

  • Graduates in engineering or technology (BE/BTech) from relevant streams
  • Graduates in sciences or computer applications (BSc, BCA and similar)
  • Final-year students awaiting results are often allowed to apply
  • Entry is usually through the C-DAC Common Admission Test (C-CAT)

What you leave with

  • Practical skill in managing Linux and Windows servers
  • Working knowledge of networks and virtualization
  • A security mindset for protecting systems and data
  • A diploma from C-DAC and placement assistance

Roles this course points to

Typical entry roles for graduates of the programme.

System administrator

Keep servers, users and services running reliably.

Network engineer

Plan, configure and troubleshoot enterprise networks.

Cloud support engineer

Operate and monitor cloud and virtualized workloads.

Security analyst

Watch for threats, review logs and respond to incidents.
